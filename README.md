# 🐱 Удивительный мир котиков

Школьный проект-презентация о кошках — самых популярных домашних животных в мире.

## 📋 Содержание

- **Интересные факты** — узнай удивительные вещи о кошках
- **Популярные породы** — обзор самых известных пород кошек
- **Уход за котиком** — советы по содержанию кошки дома
- **Галерея** — случайные фотографии котиков из интернета
- **Викторина** — проверь свои знания о кошках

## 🚀 Как открыть

Просто откройте файл `index.html` в браузере. Никаких установок не требуется!

Или разверните на любом хостинге статических сайтов (GitHub Pages, Netlify, Vercel).

## 🛠 Технологии

- HTML5
- CSS3 (анимации, адаптивный дизайн)
- JavaScript (навигация, викторина, Cat API)

## 📸 Особенности

- 🎨 Красивый дизайн с анимациями
- 📱 Адаптивная вёрстка для мобильных устройств
- ⌨️ Навигация стрелками на клавиатуре
- 🎲 Случайные фото котиков из [The Cat API](https://thecatapi.com/)
- 🎯 Интерактивная викторина с 5 вопросами
